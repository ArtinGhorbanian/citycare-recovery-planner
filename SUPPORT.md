# Support

This project is a private, local engineering preview. Support is best-effort and
limited to reproducible technical questions about the latest supported revision.
There is no service-level commitment.

## Where to ask

- Use the **Question** issue form for setup, configuration, synthetic data,
  interface, model-behavior, or contribution questions.
- Use the **Bug report** form for reproducible defects.
- Use a private GitHub security advisory for suspected vulnerabilities, as
  described in [SECURITY.md](SECURITY.md).
- Use the private repository-access channel for conduct concerns or material
  that cannot safely appear in an issue.

Before opening an issue, search existing reports, reproduce with the generated
synthetic dataset, and include the revision, operating system, Python version,
browser version when relevant, exact commands, and sanitized output.

Never post API keys, `.env` contents, patient information, personal data,
restricted competition material, or the supplied challenge dataset. Use
placeholders and the independently generated demonstration data.

## Support boundary

Maintainers can help explain the documented local workflow and investigate
project defects. They cannot provide:

- emergency response, clinical advice, diagnosis, treatment, or patient-care
  decisions;
- validation for live hospital or public-safety operations;
- legal, licensing, competition, privacy, or regulatory advice;
- support for public deployment, authentication, authorization, or rate
  limiting, which are outside the current prototype scope;
- guarantees about third-party AI services, packages, browsers, or hosting; or
- help accessing systems, data, or services without authorization.

If an immediate real-world safety or medical situation exists, use the relevant
local emergency and clinical channels instead of this repository.
